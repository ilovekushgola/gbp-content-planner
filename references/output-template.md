# Final Output Template

## 1. Business Understanding
Business Name, Category, Subcategory, City, Areas Served, USP, Positioning, Brand Tone, Story.

## 2. Local Audience Insights
City, Customer Profile, Search Behavior, Seasonal Demand, Common Questions, Objections, Festivals, Terminology.

## 3. SEO Keyword Map
Primary, Secondary, Long-tail, Semantic keywords.

## 4. Content Pillars
Selected pillars for this business.

## 5. Approved Content Plan
Table: Topic, Pillar, Service, Intent, Keyword, Local Angle, Conversion Goal, Visual Direction.

## 6. GBP Posts
Each post: Topic, Pillar, Audience, Intent, Keywords, Local Angle, Objective, Post Copy, CTA.

## 7. Visual Concepts
Each post: Concept Name, Purpose, Message, Hero Element, Style, Color, Asset.

## 8. Asset Requirements
Required real assets, brand assets, reference style per post.

## 9. AI Image Prompts
Production-ready prompt per post.

## 10. Final QA Report
Total posts, keyword coverage, service coverage, local coverage, pillar distribution, CTA distribution, missing info.
