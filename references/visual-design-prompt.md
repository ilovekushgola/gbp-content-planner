# Visual Design Prompt Template

## Master Visual Design Instruction

You are an expert modern graphic designer. Redesign from scratch for:
- Purpose, Audience, Main Message, Business, Service/Product, Location
- Color Theme, Style, Format

## Art Direction

Build composition around ONE dominant hero element.
Visual hierarchy: HERO -> SUPPORTING -> INFORMATION

Use: whitespace, scale contrast, asymmetrical balance, sophisticated typography.
Avoid: generic AI typography, excessive fonts, unnecessary effects.

## Remove AI-Slop from Visual
Remove: random objects, excessive gradients, fake 3D, particles, glows, borders, badges, decorative icons.

## One Creative Idea
ONE memorable idea: unexpected cropping, dramatic scale, typography interaction, negative space, editorial framing.

## Final Visual Feel
BOLD - MINIMAL - PREMIUM - CONTEMPORARY - INTENTIONAL - MEMORABLE

## Text on Image Rule
HEADLINE + SHORT SUPPORTING LINE + CTA only.
